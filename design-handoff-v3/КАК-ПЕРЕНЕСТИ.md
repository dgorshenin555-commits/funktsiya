## 2. Меню «Войти / Регистрация» в шапке
Сейчас в репо все четыре колбэка AuthPanel делают `window.location.href = AUTH`. Нужно как в дизайне: выпадающая панель с табами «Вход | Регистрация» и выбором роли (заказчик/исполнитель) работает на месте, без перехода на /v2/auth.
- Взять разметку и состояния из `jsx/auth_panel.jsx` + `css/auth_panel.css`.
- Вход по телефону и коду → `login` из `lib/store`; при успехе `setScr("cwork")` / `setScr("pwork")` по роли.
- «Регистрация заказчика» / «исполнителя» → `register` из `lib/store` с ролью, затем экраны `creg` → `cint` (заказчик) и `pro` (исполнитель).
- `/v2/auth` оставить как запасной вход по прямой ссылке.
