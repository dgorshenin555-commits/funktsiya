# Q: Почему useApp() соединяет сразу пять разделов приложения — что именно проходит через этот узел?

## Answer

useApp() (lib/store.tsx:220) — глобальный React-стор приложения, degree 33, betweenness 0.096. Его соседи распределены по 5 сообществам: C4 Аналитика/чат/дашборд (15: AnalyticsPage, ChatPage, DashboardPage, ExpertisePage, ExpertsPage, OrdersPage, StandardsPage, InternalLayout, Nav), C2 Профиль/layout (6: DesignerProfilePage, ManufacturersPage), C3 Авторизация/каталог (6: AuthPage, SettingsPage, DesignersPageContent), C0 Заявки (5: OrderDetailContent, NewOrderPage), C5 Лендинг (1). Каждая страница импортирует и вызывает useApp(). Это единственная общая зависимость всех разделов, поэтому узел — главный межмодульный мост. Архитектурно: один глобальный стор как единый источник правды, состояние читается/пишется в localStorage для всего приложения (см. AUDIT.md, узел 'Архитектурное ограничение: фронтенд-прототип на localStorage').
