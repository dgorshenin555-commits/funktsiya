## Overview
«Функция» — веб-платформа для проектно-изыскательских работ (ПИР): биржа заявок,
каталоги исполнителей (проектировщики, инженеры-обследователи, производители),
обследование объектов, база нормативов, тарифы, коммуникации и аналитика.
Этот пакет содержит **обновлённый визуальный дизайн** платформы (тёмная тема,
фиолетовый акцент) — лендинг + внутренние экраны приложения — для воспроизведения
в реальном кодовом окружении.

## About the Design Files
Файлы в этом пакете — это **дизайн-референсы, созданные в HTML/JSX (React + Babel,
без сборки)**. Это прототипы, показывающие задуманный внешний вид и поведение, **а не
продакшн-код для прямого копирования**. Задача — **воссоздать эти дизайны в существующем
окружении вашего кодекса** (его компонентах, дизайн-системе, библиотеках), следуя
принятым в проекте паттернам. JSX здесь использует глобальные `window.*` и инлайновый
Babel только ради автономного прототипа — в реальном приложении используйте обычные
импорты/компоненты вашего стека.

## Fidelity
**High-fidelity (hifi).** Цвета, типографика, отступы, радиусы, тени и состояния —
финальные. Воспроизводите UI попиксельно, но средствами вашей дизайн-системы.

## Каркас приложения (AppShell)
Файл-референс: `shell.jsx`. Структура внутренних экранов:
- **Sidebar 260px** слева: бренд-марка «ФУНКЦИЯ» (клик → лендинг), вертикальная навигация,
  снизу — карточка пользователя (аватар-инициалы «ДП» + имя/почта, клик → Настройки).
- **Topbar 64px**: иконка-меню, строка поиска («Поиск по заявкам»), имя пользователя + аватар.
- **Content**: скроллируемая область с `fade-in` при смене экрана; вариант `flush` (без
  внутренних отступов) для чата.
- **Legend** (футер): цветовые маркеры разделов.

## Interactions & Behavior
- Навигация: `go(screen, id)` меняет экран; подсветка пункта сайдбара через карту
  `PARENT` (под-экраны подсвечивают родителя).
- `fade-in` при смене экрана; сброс скролла контента при каждом переходе.
- Лендинг: dropdown «Главное меню» открывается по hover/click; анимированный превью-сайдбар.
- Hover-подсказки: над чипами-кодами (`.chip-code`, `.chip-toggle`, `.pill`) всплывает
  расшифровка кода раздела/стадии (`app.jsx`, `DATA.SECTION_NAMES` / `STAGE_NAMES`).
- Тема/настройки (Tweaks, `app.jsx`): переключение акцентной палитры (5 шт.), шрифта
  (Inter / Manrope / Space Grotesk), плотности (compact/regular/comfy), варианта шапки
  каталога (Слева/По центру), компоновки нормативов (Поиск/Каталог). Применяется через
  CSS-переменные на `:root`. В продакшене реализуйте только нужные опции.

## State Management
- `screen` (текущий экран), `orderId` (id для деталей заявки/обследования), `nav`
  (счётчик переходов → ключ ремоунта/сброса скролла).
- Tweaks-состояние (`useTweaks`) — для демо-переключателей темы; в реальном приложении
  замените на вашу систему тем/настроек.

## Assets
- Шрифты: Inter (woff2, локально в `fonts/`), Manrope / Space Grotesk / Poppins (Google Fonts).
- Карта: MapLibre GL JS + CSS (CDN `maplibre-gl@4.7.1`).
- Иконки: собственный набор SVG (`icons.jsx`, `window.Icon`, `window.FuncMark`).
- Брендовых ассетов сторонних компаний нет.
