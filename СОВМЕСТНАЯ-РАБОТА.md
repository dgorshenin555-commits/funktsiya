# Совместная работа над project-market

Этот файл описывает, как двое (и больше) людей, каждый со **своим** Claude Code,
вместе работают над проектом. Сервер для этого **не нужен** — общий «источник правды»
это GitHub-репозиторий `github.com/dgorshenin555-commits/projekt-market-`.

## Как это устроено (важно понимать)

Это **не** живое совместное редактирование, как в Google Docs. Это **асинхронная**
работа через git:

- У каждого на компьютере — своя локальная копия проекта (клон).
- Каждый правит файлы у себя (руками или через своего Claude Code), затем
  `commit` → `push` отправляет изменения на GitHub.
- Другой делает `pull` и забирает эти изменения к себе.
- GitHub хранит общую актуальную версию.

Главное правило, чтобы не затирать друг друга:
**сначала `pull`, потом меняешь, в конце `push`.**

## Ежедневный цикл работы

```
git pull            # забрать чужие изменения ПЕРЕД началом работы
# ... вносим правки (сами или через Claude Code) ...
git add -A
git commit -m "что сделал"
git pull            # ещё раз забрать, вдруг коллега запушил, пока вы работали
git push            # отправить своё на GitHub
```

Если оба правили один и тот же файл — git попросит разрешить конфликт.
Claude Code умеет помогать с разрешением конфликтов — просто покажите ему результат `git status`.

## Чтобы реже ловить конфликты — работайте на ветках

Для крупных независимых задач:

```
git checkout -b feat/моя-задача     # своя ветка
# ... работа, коммиты ...
git push -u origin feat/моя-задача  # запушить ветку
```

Затем на GitHub создаётся Pull Request и ветка вливается в `main`.
Для мелких правок можно работать прямо в `main` по правилу «pull → change → push».

## Первичная настройка на новой машине (для коллеги)

Коллеге нужно один раз сделать у себя:

1. Установить **Git for Windows** (включает Git Credential Manager) и **Node.js 20+**.
2. Клонировать проект в свою папку:
   ```
   git clone https://github.com/dgorshenin555-commits/projekt-market-.git project-market
   ```
3. Первый `git push` откроет браузер для входа в GitHub — войти под **своим**
   GitHub-аккаунтом. Токены вручную вписывать не нужно.

> Чтобы у коллеги было право `push`, владелец репозитория должен добавить его
> в коллабораторы: GitHub → репозиторий → **Settings → Collaborators → Add people**
> → ввести GitHub-логин коллеги. Коллега примет приглашение по ссылке из письма.

## Запуск проекта локально (предпросмотр изменений)

Чтобы видеть результат правок в браузере:

```
npm install     # один раз после клона (ставит зависимости)
npm run dev      # запускает локальный сервер на http://localhost:3000
```

Сборка статической версии (как на GitHub Pages):

```
npm run build    # результат в папке out/
```

## Деплой / публичная версия

Проект уже публикуется на **GitHub Pages**:
`https://dgorshenin555-commits.github.io/projekt-market-/`

В `next.config.ts` для production задан `basePath: '/projekt-market-'` — это нужно
именно для GitHub Pages (сайт лежит в подпапке). Менять basePath не требуется,
пока публикуем туда же.

## Технические факты о проекте

- Стек: **Next.js 16 + React 19 + TypeScript**, статический экспорт (`output: 'export'`).
- Бэкенда нет — всё состояние хранится в `localStorage` браузера.
- Карты: `maplibre-gl`. Иконки: `lucide-react`.
- Основная ветка: `main`. Ветка `gh-pages` — собранный сайт для GitHub Pages (руками не трогаем).
